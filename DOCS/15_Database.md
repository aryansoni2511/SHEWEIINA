# Database Design

## Purpose

Is document ka purpose Shewwina ka complete database structure design karna hai.

Yahan hum decide karenge:

- Database me kaunsi tables hongi.
- Har table me kaunsi information store hogi.
- Tables ek dusre se kaise connected hongi.
- Data secure aur scalable kaise rahega.
- Future me naye features add karne par database kaise expand hoga.

Ye document Backend Developer aur Database Developer ke liye blueprint ka kaam karega.
