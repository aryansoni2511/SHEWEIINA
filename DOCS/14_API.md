# API Documentation

## Purpose

Is document ka purpose Shewwina ke saare APIs ko plan aur document karna hai.

API (Application Programming Interface) Frontend aur Backend ke beech communication ka medium hota hai.

Jab user website par koi action karta hai (Login, Appointment Book, Queue Join, Payment, etc.), tab Frontend API ke through Backend se baat karta hai.

Ye document Backend Developers aur Frontend Developers dono ke liye reference guide ka kaam karega.
